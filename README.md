# 🛍️ Loja Virtual com PrimeReact e API

Projeto React que consome a Fake Store API e utiliza a biblioteca de componentes PrimeReact para exibir os produtos em cards estilizados. Também inclui um formulário para adicionar novos produtos à lista.

## 🚀 Tecnologias Utilizadas
- **React** (Vite)
- **PrimeReact** e **PrimeFlex** (Componentes e Grid responsivo)
- **Axios** (Consumo da API)
- **Fake Store API**

## ⚙️ Como rodar o projeto
1. Clone o repositório.
2. Instale as dependências: `npm install`
3. Rode o projeto: `npm run dev`
4. Acesse: `http://localhost:5173`

## 📱 Funcionalidades
- Consumo em tempo real da Fake Store API.
- Cards responsivos com imagem, descrição, categoria e botão de compra.
- Formulário interativo para adicionar novos produtos (atualizando o estado da lista).
